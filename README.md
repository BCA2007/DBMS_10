# Student Record Management System (Python + MySQL)

## Features
- Add, view, search, update, and delete student records.
- Real MySQL persistence (records remain after closing the application).
- Input validation for required fields, email, semester (1–8), and optional phone.
- Duplicate email handling and delete confirmation.
- Parameterized SQL queries to reduce SQL injection risk.
- Table automatically created by the application if it does not exist.

## Requirements
- Python 3.10 or newer
- MySQL Server 8.x (MySQL service must be running)
- Python package `mysql-connector-python`
- Tkinter (included with most standard Windows Python installations)

## Setup (Windows / VS Code)
1. Install and start MySQL Server. Remember the password for the `root` account.
2. Open this project folder in VS Code.
3. Open `app.py` and change `YOUR_MYSQL_PASSWORD` in `DB_CONFIG` to your actual MySQL password. Do not share your password.
4. Open VS Code Terminal (`Terminal > New Terminal`) and run:
   ```bash
   py -m pip install mysql-connector-python
   ```
   If `py` is unavailable, use `python -m pip install mysql-connector-python`.
5. Optional: open MySQL Workbench, run `database.sql`, and confirm `student_db` and `students` exist. The application can also create the database/table automatically.
6. Run:
   ```bash
   py app.py
   ```
7. Test Add Student, search, Update Selected, Delete Selected, and confirm the data in MySQL Workbench with:
   ```sql
   USE student_db;
   SELECT * FROM students;
   ```

## How to use
- Enter name, email, course, and semester. Phone is optional.
- Click **Add Student** to insert a new record.
- Click a row to load its details into the form.
- Edit fields and click **Update Selected** to update that record.
- Select a row and click **Delete Selected** to remove it after confirmation.
- Type into the search box to search by name, email, or course.
- **Clear Form** clears the selected record and input fields.

## Database schema
`students(student_id, name, email, course, semester, phone, created_at)`
- `student_id`: auto-increment primary key
- `email`: unique and required
- `name`, `course`, `semester`: required
- `phone`: optional
- `created_at`: timestamp automatically generated by MySQL

## Common errors
- **Access denied**: check the MySQL username/password in `app.py`.
- **Can't connect / connection refused**: start the MySQL service and confirm port 3306.
- **No module named mysql**: run `py -m pip install mysql-connector-python`.
- **Duplicate email**: use a different email address.
- If your MySQL root account uses no password, set `password` to an empty string (`""`).

## Demonstration checklist
1. Show `student_db` and `students` in MySQL Workbench.
2. Add a new record through the app.
3. Run `SELECT * FROM students;` and show the inserted row.
4. Update the record in the app and rerun SELECT.
5. Delete the record in the app and rerun SELECT to prove it is gone.
6. Close and reopen the app; remaining records should still appear.
